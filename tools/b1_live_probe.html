B1 live data probe

Read-only diagnostic for public Bybit V5 Linear klines. It captures concurrent 1D / 4H / 1H responses, provider timestamps and raw response payloads. It does not create signals or place orders.

Recommended initial run: BTCUSDT, 30 samples, 3000 ms delay, 200 rows. One sample makes three concurrent kline requests. If the primary host fails, the probe tries the configured backup host. Run this page from localhost HTTP, not by opening it as file://. If you press Stop during a sample, that incomplete sample is discarded; previously completed samples remain available for export.
