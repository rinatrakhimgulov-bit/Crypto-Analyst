# Скриншоты проекта Crypto Analyst

Здесь хранятся скриншоты интерфейса, проверок и визуальных результатов разработки.

## Как добавлять материалы

- Загружайте изображения в эту папку через GitHub: Add file → Upload files.
- Используйте понятные имена с этапом, датой и контекстом, например `B1_quality-panel_2026-11-27_iPhone-Safari.png`.
- Для каждого изображения указывайте в описании, что именно проверялось, устройство и браузер.
- Не загружайте сюда секреты, API-ключи, пароли, приватные данные или большие необработанные логи.
- Скриншоты, относящиеся к незавершённой работе, добавляйте в соответствующую рабочую ветку или обсуждение PR, а не напрямую в `main`.

## Рекомендуемая структура

- `B1/` — панель качества данных и проверки B1.
- `B2/` — структура рынка и визуализация B2.
- `UI/` — общие изменения интерфейса.

Git не хранит пустые папки, поэтому этот README создаёт каталог. Подпапки появятся после добавления в них файлов.
